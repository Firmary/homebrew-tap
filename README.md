# Firmary for Homebrew

```sh
brew install firmary/tap/firmary
```

Installs `firmary`, Firmary's command line, on macOS and Linux. The formula downloads the release
from firmary.app and checks its SHA-256. Upgrade with `brew upgrade firmary`.

Guide: https://firmary.app/docs/cli. Other ways to install: https://firmary.app/download.

This repository holds only the formula (`Formula/firmary.rb`), copied from firmary.app with each
release. Firmary's source is not public. Terms: https://firmary.app/terms.
